Aquí van las voces de los videos, un archivo por video, con el mismo nombre que el id del video:

  public/audio/<id>.mp3   (también vale .wav o .m4a)

Ejemplo: para el video "cielo-azul-tiktok" → public/audio/cielo-azul-tiktok.mp3

- Si usas ElevenLabs con tu clave, el audio se guarda aquí solo (npm run voz:ia -- <id>),
  con la voz de cada personaje.
- Si grabas tu voz o usas otra app (CapCut, ElevenLabs web…): lee el guion por voces
  (out/<id>-guion-voz.txt) EN ORDEN, con una pausa corta entre línea y línea, guarda aquí el audio
  con ese nombre y luego corre: npm run sincronizar -- <id>
